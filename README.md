# 記帳系統 (Accounting)

Streamlit + SQLite 的記帳系統，解析半結構化中文記帳文字，產出統計報表。
電腦當 server，電腦與手機共用同一個資料庫；手機連線時自動使用手機版面。

## 啟動

```bash
./run.sh                                          # 預設，網址 http://localhost:8501
./run.sh --server.address "$(tailscale ip -4)"    # 只讓 Tailscale 內的裝置連得到
```

第一次執行會自動建立 `.venv` 並安裝套件。如果資料夾搬過位置導致 `bad interpreter`，
把 `.venv` 改名或刪掉再執行一次即可。

## 手機連線（Tailscale）

1. 電腦與手機都登入同一個 Tailscale 帳號。
2. 電腦上執行 `tailscale ip -4` 取得電腦的 Tailscale IP（也可以用 MagicDNS 的主機名稱）。
3. 手機瀏覽器開啟 `http://<電腦的 Tailscale IP>:8501`。

Streamlit 本身沒有登入功能，請不要把埠直接開到公開網路；建議用上面的
`--server.address` 只綁在 Tailscale 網卡上，這樣家裡區域網路的其他裝置也連不到。

## 版面：自動、手機版、桌面版

- 預設「自動」：依連線裝置的 User-Agent 判斷，手機（iPhone / Android）使用手機版面，其餘使用桌面版面。
- 側邊欄（手機是左上角 `»`）的「顯示設定」可手動切換；也可以在網址後面加 `?view=mobile` 或 `?view=desktop`。
- 手機版面：年月與報表篩選移到主畫面、左右並排的欄位改成上下堆疊、報表卡片單欄、按鈕加大。
  四個頁面（輸入、審核、報表、關係表）功能與桌面版相同；人員管理在側邊欄裡。

## 資料

- 資料庫：`accounting.db`（SQLite，與程式放在同一個資料夾）。**不會進 git**（見 `.gitignore`），要備份請直接複製這個檔案。
- `History/`（原始歷史文字，供報表「對帳」使用）同樣不進 git。

## 輸入頁的「來點魔法」

把原始文字整理成程式好處理的格式（左邊原始資料、右邊整理後的資料）：

- ⚠️ 備忘拆成一品項一行，金額統一寫成 `+$金額`，算式保留在括號內。
- 類別行裡不是人名的項目（例如 `晚餐：傑森烤肉裕毛屋棉花田`）拉成 ⚠️ 備忘。
- 獨立一行的「人名＋類別」（例如 `阿鵰點心+70`）視為該類別的支出，整理時補成 `點心：阿鵰點心+70`。
  代理關鍵字（例如米媽媽）與電費不適用，維持備忘。
